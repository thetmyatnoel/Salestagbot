Automatic publishing setup

Do these five points once, on this PC. Points 1 to 4 take about 30 minutes. Point 5 takes about 15 minutes and can wait until the phone app is ready. Afterwards Claude can publish your updates for you.

Keep this page open in your browser. Point 1 asks you to close the Claude app. To open this page, open File Explorer, go to Desktop (바탕 화면), Noel, docs, and double-click AUTO-PUBLISH-SETUP.html. If you restart the PC, open it again the same way. The ticks you set are kept.

The shop account. This guide means the Google account that owns the shop Sheet. It is the account you use for Extensions, Apps Script and Deploy. Use the same account in every point.

Command Prompt, not PowerShell. Type every command in Command Prompt (명령 프롬프트). To open it, press the Windows key, type cmd and press Enter. PowerShell on this PC blocks these tools with a red error.

Korean screens. Windows on this PC is in Korean, so its own windows show Korean text. This guide gives the Korean text next to the English. Google's pages can also be in Korean, depending on your account's language. The buttons are in the same places.

1Install the newer Node.jsabout 10 min

The two publishing tools need Node.js version 20 or newer. This PC has version 16.7. The installer below is Node.js 24, a long-term support version that both tools work with.

  1. Save your work. Close every Command Prompt, PowerShell and VS Code window.
  2. Quit the Claude app completely. At the bottom right of the screen, near the clock, find the Claude icon. If you do not see it, click the small ^ arrow there first. Right-click the Claude icon and choose Exit (종료). Wait about 10 seconds until the icon disappears. Closing the window alone leaves the app running. Your conversation is kept, and after this point you may open Claude again at any time if you get stuck.
  3. In your browser, open this address. It downloads the file node-v24.22.2-x64.msi, about 33 MB, from the official Node.js site.
    https://nodejs.org/dist/v24.22.2/node-v24.22.2-x64.msi
  4. Open your Downloads folder (다운로드) and double-click node-v24.22.2-x64.msi. A window called Node.js Setup opens. Its screens are in English.
  5. On Welcome to the Node.js Setup Wizard, click Next.
  6. On End-User License Agreement, tick I accept the terms in the License Agreement, then click Next.
  7. On Destination Folder, leave C:\Program Files\nodejs\ as it is and click Next.
  8. On Custom Setup, change nothing and click Next.
  9. On Tools for Native Modules, leave the checkbox empty and click Next. Ticking it downloads several gigabytes the tools do not need.
  10. On Ready to install Node.js, click Install. Windows asks in Korean whether to allow the app, for example 이 앱이 디바이스에 소프트웨어를 설치할 수 있도록 허용하시겠어요? Click 예 (Yes).
  11. If a Files in Use window appears, choose Close the applications and attempt to restart them. and click OK.
  12. Wait for Completed the Node.js Setup Wizard, then click Finish. The old version 16 is replaced. You do not need to uninstall it first.
  13. Open a new Command Prompt. Type this and press Enter:
    node -v
    It must show v24.22.2 or a higher number. If it still shows v16.7.0, restart the PC, open this page again, and check once more.

2Turn on the Apps Script APIabout 3 min

This switch lets tools on this PC upload code to your Apps Script. It does not change how the bot runs. You can switch it off again at any time.

  1. Open a private window: press Ctrl + Shift + N. Chrome calls it an Incognito window (시크릿 모드). It is dark, with a hat-and-glasses icon. It is the same kind of window that opened the shop Sheet before.
  2. In that private window, go to accounts.google.com and sign in with the shop account only. Do not add any other account in this window.
  3. In the same private window, open this address:
    https://script.google.com/home/usersettings
  4. Click the round picture at the top right. Check that it shows the shop account's email.
  5. Find the row Google Apps Script API and click it. A panel with a switch opens.
  6. Click the switch so it turns On. Close the panel and check that the row now says On.
  7. Keep this private window open for points 3, 4 and 5. If it gets closed, for example after a restart or when you do point 5 another day, open a new one and sign in again exactly as in steps 1 and 2. Never use a normal window for points 4 and 5. The switch can take a few minutes to start working. You do not need to wait for it.

3Install the tools and sign in to claspabout 10 min

clasp is Google's tool for Apps Script, and the Firebase tool is for the phone app. Both get installed now. You sign in yourself, so Claude never types a password.

  1. In Command Prompt, type this and press Enter. It takes 1 to 3 minutes.
    npm install -g @google/clasp firebase-tools
    It is finished when you see a line starting with added and the blinking cursor comes back. Yellow lines with npm warn deprecated are normal.
  2. Close Command Prompt and open a new one. Type these two commands, pressing Enter after each:
    clasp --version
    firebase --version
    The first should show 3.4.1 or higher, and the second 15 or higher.
  3. Type this and press Enter:
    clasp login
    Command Prompt shows Authorize clasp by visiting this url: and a long address, and a browser tab opens by itself. Leave Command Prompt open. It waits for you. Windows may also show Windows Defender 방화벽에서 이 앱의 일부 기능을 차단했습니다. for Node.js. Click 취소 (Cancel). Sign-in still works, because it only talks to this PC.
  4. In the browser tab, Google asks you to Choose an account. Click the shop account. If you are not sure which account is right, use the private-window method in the next step instead.
  5. Only if the previous step did not work: close that tab. In Command Prompt, drag the mouse over the whole long address, from https to its end. It may wrap over several lines. Press Enter to copy it. Paste it into the address bar of your private window from point 2 and press Enter.
  6. Google shows a page saying clasp wants to access your Google Account, with a list of permissions. The list is long because clasp manages scripts and their deployments. If you see tick boxes, click Select all. Then click Continue or Allow.
  7. The browser shows Logged in! You may close this page. Command Prompt shows You are logged in as and an email. That email must be the shop account.
  8. If the email is wrong, type clasp logout, press Enter, and repeat from step 3 using the private-window method.
Sign-ins are saved on this PC. clasp saves yours in C:\Users\USER\.clasprc.json. After point 5, the Firebase tool saves one in C:\Users\USER\.config\configstore\firebase-tools.json. Whoever has these files can change your scripts and your Google Cloud and Firebase projects. Never send, email or upload them. Also never send a screenshot of the Script Properties part of Project Settings, or of a registerWebhook or webhookStatus log. They show your bot token, Gemini key or webhook secret. How to remove the access is at the end of this page.

4Find the Script ID and the web app addressabout 5 min

The Script ID tells clasp which project to update. The web app address is the /exec address Telegram already uses. It contains the Deployment ID, so every update goes to the same address and the webhook never needs changing. Neither is a password, but do not post them in public.

Script ID

  1. In your private window with the shop account, go to sheets.google.com and click the shop Sheet. If it is not in the list, or Google says you need access, this window is signed in with the wrong account. Close all private windows and do point 2 steps 1 and 2 again.
  2. In the Sheet, click Extensions, then Apps Script. The editor opens in a new tab.
  3. On the far left of the editor is a narrow column of icons. Click the gear icon, Project Settings. It is the last icon.
  4. Under IDs, next to Script ID, click Copy.
  5. Open Notepad, paste it, and write Script ID next to it. It is a long code that usually starts with 1. It is not the Sheet's own ID from the Sheet's address.

Web app address

  1. In the same editor, click the blue Deploy button at the top right, then Manage deployments. Do not click Test deployments or New deployment.
  2. The window lists your active deployments on the left. If there is only one, it is already selected. Go to step 4.
  3. Only if there is more than one: you need the one Telegram uses. Click Done. Click the gear icon Project Settings and scroll down to Script Properties. Read the value next to WEBAPP_URL. Do not copy or photograph the other rows, because BOT_TOKEN, GEMINI_KEY and WEBHOOK_SECRET are passwords. Open Deploy, Manage deployments again. Click each deployment on the left until the web app address on the right is exactly the same as WEBAPP_URL.
  4. On the right, under Web app, find the address that ends in /exec and click the Copy next to it. Paste it into Notepad and write Web app address next to it. It starts with https://script.google.com/.
  5. If the right side shows Execute as with an email, that email must be the shop account. If it shows a different email, stop and tell Claude before going further.
  6. Close the window with Done or the X without changing anything.

5Firebase for the phone appabout 15 min, can wait

Firebase Hosting serves the phone app's files for free. Creating the project means accepting Google's terms, so you do it yourself. Skip this point for now if you only want the bot updates automatic.

Create the project

  1. Open a private window with only the shop account signed in, as in point 2 steps 1 and 2. Then open:
    https://console.firebase.google.com
  2. Click the button that creates a new project. Its label changes from time to time, for example Create a project, Create a new Firebase project or Get started with a Firebase project. Ignore tiles about Firebase Studio or building with AI.
  3. Type a project name, for example SalesTagBot. Under the name, Firebase shows a project ID. Click the small pencil next to it and type a clean ID, for example salestagbot-shops. Use 6 to 30 lowercase letters, digits and hyphens. Start with a letter, do not end with a hyphen, and do not use the words google or ssl. This ID can never be changed. Claude will use it for the app's web address, https://ID.web.app. If it is taken, try another.
  4. If it is your first Firebase project, tick I accept the Firebase terms. If a second box about using Firebase for your trade, business, craft or profession appears, tick it too. Click Continue.
  5. If a step about AI assistance or Gemini in Firebase appears, make sure its switch is off. Click the switch if it is on. Then click Continue.
  6. On the Google Analytics step, switch off Enable Google Analytics for this project. Click Create project.
  7. Wait for Your Firebase project is ready, then click Continue. The plan shown at the bottom left should say Spark, which is free. Never click Upgrade. The paid plan needs a bank card, and the app does not need it.
  8. Do not open Hosting, and do not click Get started there. That can create the app's address with random letters added, permanently. Claude creates the address from this PC instead. Write the project ID in Notepad.

Sign in to the Firebase tool

  1. Use a Command Prompt opened from the Start menu, not a terminal inside the Claude app. Type this and press Enter:
    firebase login
  2. It asks Enable Gemini in Firebase features? (Y/n). Type n and press Enter.
  3. It asks Allow Firebase to collect CLI and Emulator Suite usage and error reporting information? (Y/n). Type n and press Enter.
  4. A browser tab opens. Choose the shop account. If the wrong account appears, use the private-window method from point 3: copy the address printed after Visit this URL on this device to log in: into your private window.
  5. On the page saying Firebase CLI wants to access your Google Account, click Select all if you see tick boxes. Then click Continue or Allow.
  6. The browser shows Firebase CLI Login Successful. Command Prompt shows Success! Logged in as and the shop account's email.
  7. Type this and press Enter. Your project ID must be in the list.
    firebase projects:list

✓When you finish

  1. Open the Claude app again from the Start menu and open this conversation. Restarting it lets Claude use the new Node.js.
  2. Paste these into the chat: the Script ID, the web app address, and your bot's Telegram username, which ends in bot, without the @. Add the Firebase project ID if you did point 5.

Claude then saves a copy of the code that is online now and notes which version the bot runs, so it can switch the bot back in one step. It sets up the one-step publish, publishes once, and checks that the web app still answers. From then on you will not need to paste Code.gs again.

Two things stay with you. Some updates add tabs or columns. For those, Claude tells you which function to run once in the editor, for example setupSheet. If Google then asks for permission, you click Allow yourself.

Removing the access later

  1. In Command Prompt, type clasp logout and press Enter, then firebase logout and press Enter. This removes the saved sign-ins from this PC. firebase logout also cancels the Firebase tool's access at Google.
  2. In a private window with only the shop account signed in, open https://myaccount.google.com/linkedapps. Click Access to your Google Account, then the entry whose name starts with clasp, then See details, Remove access and Confirm. Do the same for Firebase CLI if it is still listed.
  3. To be fully sure no tool can change the code, switch Google Apps Script API off again on the page from point 2. The bot keeps working.
