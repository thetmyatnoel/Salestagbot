# MAP sim
The browser simulator in `poc/`: one self-contained HTML page (`poc/dist/pos-simulator.html`, 517 KB today) that runs the unchanged core (`apps-script/core_*.js`) over in-memory ports, draws a Telegram phone, a shop floor of QR tags and the Google Sheet, and the Node harnesses that drive the same core. Written for the round-5 spec (BRIEF D7, D8): what exists, where, and how a v2 page can host the Telegram phone and the real app over one world.
